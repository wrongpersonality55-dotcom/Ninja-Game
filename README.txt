SHADOW NINJA 3D - GitHub Pages par lagane ka tareeqa

1. github.com par naya repository banao (naam e.g. shadow-ninja, Public).
2. Is zip ko EXTRACT karo, phir saari files (index.html, sw.js, manifest.webmanifest, icons) repository ke ROOT mein upload karo (folder ke andar nahi).
3. Repo > Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
4. 1-2 minute baad link milega: https://USERNAME.github.io/shadow-ninja/
5. Phone (Chrome): link kholo > menu > Install app / Add to Home screen. iPhone (Safari): Share > Add to Home Screen.
   Laptop (Chrome/Edge): address bar mein install icon dabao.

Offline: pehli baar internet ke saath kholna zaroori hai (3D engine download hota hai). Uske baad bina internet ke chalti hai.
Update karne par sw.js mein shadow-ninja-v1 ko v2 kar do, taake purani cache badal jaye.
